# Wise Business Forms – January 1991 Distributor Price List

A Markdown transcription of the scanned `../January 1991 Wise Price Book.pdf` (20 pages), covering the plant's rules, price tables and other printed text. There is one file per PDF page in [`pages/`](pages/), and [`price-book.html`](price-book.html) has every page in a single self-contained web page.

**Notes on the transcription**
- Prices and rules are transcribed exactly as printed, including values that look like misprints. Uncertain readings are marked `[?]`.
- Handwritten checkmarks were left out. Other handwritten notes on the scan are listed under "Handwritten annotations" on each page.
- To rebuild the HTML after editing the Markdown, run `./build_html.sh` (requires pandoc).
